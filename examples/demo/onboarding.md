# Onboarding

Welcome to Atlas. This page has no YAML frontmatter on purpose: lodestar does
not require any — plain Markdown is a first-class citizen.

Your first week:

1. Read the [overview](overview.md) and the [architecture](architecture.md).
2. Shadow one deploy following the [deploy runbook](runbooks/deploy.md).
3. Skim the accepted decisions, starting with
   [ADR-0001](adr/0001-markdown-source-of-truth.md).
